# Mobile map Photo control — 0.70.14

The compact mobile map button and photo panel heading use the short label
**Photo**. The button still toggles the validated vessel photo panel.

This version also includes the 0.70.13 correction: the mobile Legend panel
opens within the phone viewport, and each new fullscreen map session starts
with Legend closed.

Install via **System → Advanced Maintenance → Update** with beta/develop
selected. Verify the **Photo** button opens and closes the photo panel, and
verify Legend opens fully on screen. The Android APK remains version `2.0.7`.
