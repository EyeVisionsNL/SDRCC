# SDRCC v0.54.0m — Mission History Visual Clarity

## Scope

This release refreshes the Mission History presentation while preserving the v0.54.0c integrity contract.

- No History writer, stored result, classification, API route or delete rule changes.
- No new recorder, decoder, scheduler, service or runtime authority.
- Existing search, result filter, limit, selection, gallery and exact-mission delete actions remain intact.
- The 15-second refresh still runs only while Mission History is active.

## Visual contract

- METEOR-M2 3 uses cyan, METEOR-M2 4 purple and ISS yellow.
- SUCCESS uses green; NO SYNC, NO SIGNAL and NO IMAGES use amber; FAILED uses red.
- Satellite identity and mission outcome remain separate visual dimensions.
- Summary cards, selected mission detail, quality, files and image gallery use the approved SDRCC theme.
- Receiver aliases are displayed as SDR1 or SDR2 without changing stored receiver identity.
- Mission History presentation text and locale are English.
