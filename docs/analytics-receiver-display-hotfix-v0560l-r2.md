# SDRCC v0.56.0l-r2 — Analytics Receiver Display Hotfix

Hotfix for v0.56.0l.

- Receiver Performance now applies the existing display-only receiver normalizer.
- Historical RX01/RX02, receiver01/receiver02 and sdr1/sdr2 values display as SDR1/SDR2.
- Satellite performance labels are unchanged.
- Fixes the malformed analytics receiver-label escape call introduced in r1.
- Mission History and Receiver Registry data are not modified.
