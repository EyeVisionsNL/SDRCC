# SDRCC v0.56.0m-r3 — Home Position Maintenance Polish

Presentation-only hotfix for Configurable Home Position.

- Moves Home Position from the normal System workflow into the existing
  Advanced Maintenance disclosure because station location is normally a
  one-time setup action.
- Reuses the existing Advanced Maintenance amber theme, neon left rail,
  corner accent and closed-by-default behaviour.
- Keeps the Home Position title and explanation on one line where space allows.
- Places location, latitude, longitude, altitude and both actions in one compact
  desktop row.
- Keeps all v0.56.0m API, station authority, planning, Radio View and Doppler
  behaviour unchanged.

No backend, configuration or authority change is part of r3.
