THE SDRCC GUIDE / INSTALLATION

From zero to receiving.

Install SDRCC on Ubuntu. We’ll take it one step at a time.

Requirements: Ubuntu Linux x86-64, internet access and suitable RTL-SDR hardware. A Raspberry Pi is not the reference platform for full SDRCC.

1. Install

Open a terminal as your normal Ubuntu user:

sudo apt-get update
sudo apt-get install -y git
git clone --depth 1 --branch main https://github.com/EyeVisionsNL/SDRCC.git ~/SDRCC
cd ~/SDRCC
bash install.sh

Do not use sudo bash install.sh: the installer asks for permissions when needed.

2. Configure

Enter your station name, coordinates and altitude. Follow the AIS-catcher prompts. Receivers can be connected and assigned later.

Before opening the AIS-catcher wizard: Keep the serial number of the RTL-SDR you want to use for AIS handy. Enter it in the AIS-catcher SDR input so you can complete Save & Close. Then return to SDRCC Installer and choose Verify AIS setup. SDRCC receiver bindings can still be changed later.

3. Open the dashboard

Visit http://localhost:8080 on the SDRCC computer, or use its IP address on your trusted network. Open System.

AIS setup later? Stop active missions and Radio Receiver, then run cd ~/SDRCC && bash install.sh --ais-setup. For existing stations, update with System → Advanced Maintenance.
